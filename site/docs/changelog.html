Changelog

What changed in each release.

0.14.0

  • Hub majority election for three or more hubs (election safety, not a replicated log).
  • Kernels: whole-grid reductions with shared memory (Metal), HIP source generation, reserved-name checks.
  • Soak test, weekly re-verification workflow, new site pages.

0.13.0

  • Hub active/standby failover (about 6.7 s measured), read-only dashboard, alerts with optional webhook.

0.12.x

  • Virtual interconnect, portable kernels, fair share / gang / cache-affinity in the hub.
  • Protocol hardening (handshake timeout, connection cap, listen backlog), hub persistence, scale and fuzz tests.
  • Planner: a third probe when the first two cannot separate fixed cost from speed.

0.11.0

  • Accelerator fabric: one job on CPU, Metal or NVIDIA, chosen by measured cost.

0.10.0

  • One objective for every engine: the planner.

0.9.0

  • Fleet: agent, hub, recommendations.
