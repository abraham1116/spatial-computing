Fleet

An agent on every machine, a hub that sees the whole fleet: measure, place, recommend, audit.

ScopeValidated with up to 3 agents on one machine. The three report the same CPU load, so this proves the chain (identity, scopes, placement, results, audit), not scaling.

The parts

  • Agent (spatial agent): measures CPU, RAM, memory pressure and NVIDIA GPUs every few seconds, reports to the hub, asks for work and runs it. Outbound connections only. Buffers measurements while the hub is down and delivers them with their original times.
  • Hub (spatial serve hub): keeps each node's measurements, queues and places tasks, computes utilization and recommendations. It never changes a machine by itself.
  • Operator CLI (spatial fleet): status, recommendations, submit, result.

Run it

spatial token init --master-key-file hub.key
spatial serve hub --master-key-file hub.key --port 7700
spatial token issue --master-key-file hub.key --name node-1 --scopes fleet:report,fleet:work > node-1.tok
spatial token issue --master-key-file hub.key --name ops --scopes fleet:read,fleet:submit > ops.tok
# on every machine
spatial agent --hub HUB:7700 --token-file node-1.tok --usd-per-hour 1.5
# the operator
spatial fleet status --hub HUB:7700 --token-file ops.tok
spatial fleet advise --hub HUB:7700 --token-file ops.tok
spatial fleet submit --hub HUB:7700 --token-file ops.tok --workload mandel_numba --params '{"n":1400,"iters":300}'

Placement

Pull-based. An agent asks for work and receives the best queued task it is eligible for: priority first, then arrival order. Tasks can require a GPU, a minimum of free RAM, a label or a pinned node. A node at 90 % CPU or more receives nothing. Every placement is recorded, with its reason, in a hash-chained decision log. Agents run only allow-listed workloads by name: no code travels to an agent.

Recommendations

KindTriggered by
node_downNo report for 30 s
memory_pressureLess than 10 % RAM free
gpu_underusedGPUs below 20 % on average
rebalanceA node at 80 % or more next to a node at 15 % or less
consolidateThe fleet's busy cores would fit on fewer nodes at a 60 % target, RAM checked at 85 %

Each one shows its evidence and its assumptions. A saving in dollars appears only if you gave the machine's price (--usd-per-hour), and it is an estimate: it becomes a result only when you apply the change and measure the fleet again.

Security

Encrypted, forward-secret transport. With scoped credentials, a node's identity is its credential name: an agent cannot report as another node, cannot read the fleet and cannot submit tasks; a reader cannot inject measurements. Quotas, expiry, revocation and an audit log apply. Not independently reviewed.

Limits

Single-process hub with in-memory state (no persistence, no high availability), no dashboard UI, heuristic recommendations, placement that does not move running work. Full description: docs/INFRASTRUCTURE.md.
