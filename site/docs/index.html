Documentation

Spatial Computing measures, compares and chooses how a workload runs. Here is where to start.

ConsoleCreate an account, an app, an API key; send jobs; watch usage and pay. QuickstartFrom zero to a first job, with the console or the CLI. REST APIEverything the console does, for scripts. Compute EngineDetect, monitor, compare strategies, offload. Tiered memoryHot, compressed, far: a priced trade-off, not RAM. Runtime EngineInspect a binary, pick a route, run it isolated. SPATIAL QLanguage, compiler, OpenQASM 3, backends. Accelerators and kernelsOne job on CPU, Metal, NVIDIA or AMD; kernels written once. InterconnectEncrypted collectives with a measured cost model. OperationsFailover, dashboard, alerts, scale. RoadmapWhat is built, what needs hardware or people. ResultsEvery measured number and its conditions.
StatusVersion 0.22.0. Four engines are operational and tested (274 tests) on a single Mac and in CI on Linux. Nothing has been proven on a second machine, a data-center GPU or a QPU. See Limitations.

Principles

  • A measurement before any claim. Every run produces a Measurement; failures are kept.
  • Verified result. A faster strategy is kept only if it computes the same thing as the reference.
  • Explicit refusals. What a machine cannot do is stated with the reason, never faked.
  • No implicit network exposure. Everything listens on loopback by default.
