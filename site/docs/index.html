Documentation

Spatial Computing measures, compares and chooses how a workload runs. Here is where to start.

InstallVenv, dependencies, first command in three minutes. Compute EngineDetect, monitor, compare strategies, offload. Tiered memoryHot, compressed, far: a priced trade-off, not RAM. Runtime EngineInspect a binary, pick a route, run it isolated. SPATIAL QLanguage, compiler, OpenQASM 3, backends. ResultsEvery measured number and its conditions.
StatusVersion 0.12.2. Four engines are operational and tested (153 tests) on a single Mac and in CI on Linux. Nothing has been proven on a second machine, a data-center GPU or a QPU. See Limitations.

Principles

  • A measurement before any claim. Every run produces a Measurement; failures are kept.
  • Verified result. A faster strategy is kept only if it computes the same thing as the reference.
  • Explicit refusals. What a machine cannot do is stated with the reason, never faked.
  • No implicit network exposure. Everything listens on loopback by default.
