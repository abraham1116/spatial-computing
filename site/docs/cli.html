Commands

Every command of the spatial command line.

CommandRole
spatial audit [--json]Hardware, current usage, limits of this machine
spatial statusReal status of every engine and what is not done
spatial plan <file>Detected format and execution routes, with reasons
spatial run <file> [args] [--route R] [--timeout S]Runs via the first feasible route; exit code 1 if impossible
spatial bench cpu|memory|gpu|runtime|allRedo the measurements and regenerate the results table
spatial serve compute|memory|runtime --token-file F | --master-key-file FStart a worker, a page server or a sandboxed binary runner, on loopback; with a master key, tenants get scoped credentials
spatial optimize compute|binary|dataset|kv [--objective cost|time --deadline S --max-ram-gib G --isolated --execute]The one objective: price every option for a job, pick the cheapest, optionally run it and compare with the estimate
spatial devicesCompute devices the planner can use on this machine
spatial agent --hub H:P --token-file F [--usd-per-hour X]Run a fleet agent: measure this machine, report to a hub, run allow-listed tasks
spatial fleet status|advise|submit|result --hub H:P --token-file FSee the fleet, get recommendations with their evidence, submit and read tasks
spatial serve hub --master-key-file F [--state-file S] [--peer H:P --name N]Start the fleet hub; with a state file it survives restarts; with a peer it joins an active/standby pair
spatial dashboard --hub H:P --token-file FRead-only fleet dashboard on 127.0.0.1, behind a random key
spatial watch --hub H:P --token-file F [--webhook URL]Print alerts as they fire and clear
spatial token init|issue --master-key-file F [--name N --scopes S --ttl T --max-ops N --max-bytes B]Create a master key; issue a scoped, expiring, quota-limited credential

An error prints a single spatial: Type: message line and exits with code 1.
