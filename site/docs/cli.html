Commands

Every command of the spatial command line.

CommandRole
spatial audit [--json]Hardware, current usage, limits of this machine
spatial statusReal status of every engine and what is not done
spatial plan <file>Detected format and execution routes, with reasons
spatial run <file> [args] [--route R] [--timeout S]Runs via the first feasible route; exit code 1 if impossible
spatial q run|check|qasm|ir <file.sq>Run, check, export to OpenQASM 3 or to SQIR
spatial bench cpu|memory|gpu|runtime|q|allRedo the measurements and regenerate the results table
spatial serve compute|memory --token-file FStart a worker or a page server, on loopback

An error prints a single spatial: Type: message line and exits with code 1.
