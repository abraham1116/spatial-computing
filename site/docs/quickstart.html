Installation

Python 3.10 or newer. Tested on macOS 13 (Intel) with Python 3.13, and in CI on Linux and macOS.

Not on PyPI yetInstall from the sources of the GitHub repository.

1. Environment

git clone https://github.com/abraham1116/spatial-computing && cd spatial-computing
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[quantum]"

The quantum extra adds Qiskit, Qiskit Aer and the OpenQASM 3 importer. Without it SPATIAL Q works with its built-in simulator but not with the aer backend.

numpy (< 2.2) and numba (< 0.62) are bounded: newer Numba needs an llvmlite that does not build on the reference Mac.

2. Verify

spatial audit
spatial status
pytest

3. Linux micro-VM (optional)

The microvm route of the Runtime Engine needs QEMU (for example sudo port install qemu with MacPorts) and two files downloaded once into vendor/, checked by SHA-256.

mkdir -p vendor && cd vendor
curl -O https://dl-cdn.alpinelinux.org/alpine/v3.22/releases/x86_64/netboot/vmlinuz-virt
curl -o busybox-x86_64 https://busybox.net/downloads/binaries/1.35.0-x86_64-linux-musl/busybox
shasum -a 256 -c SHA256SUMS

4. Test binaries (optional)

To reproduce the runtime tests, install the build extra (the ziglang cross-compiler) and run spatial bench runtime: it compiles the same C program for macOS, Linux, Windows and WASM into benchmarks/build/.
