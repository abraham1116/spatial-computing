Runtime Engine

Inspects a binary, lists the possible execution routes with the reason for every refusal, and runs the first feasible one.

Inspect and plan

spatial plan identifies the format (Mach-O, ELF, PE, WASM, script), the target system and architecture from the headers, then lists the routes. A route is marked feasible only if its prerequisites were detected on the machine.

Run

spatial run takes the first feasible route (or the one given with --route) and returns the program's output.

RouteUseIsolation

WindowsWith Wine present, a Windows console binary runs and returns the reference checksum. Without Wine the engine says so instead of pretending. Wine is never installed automatically (third-party build, user consent required). Graphical applications are untested.
