SPATIAL Q

A hybrid workflow language: classical, distributed and quantum, with backend choice from a resource estimate.

HonestyEverything that runs is classical simulation. No QPU is connected and no quantum speed-up is measured.

A program

quantum bell() {
    qubit q[2];
    h q[0];
    cx q[0], q[1];
}

task heavy(n: int) on any {
    return workload("mandel_numba", n = n, iters = 200);
}

main {
    let counts = sample bell() shots 2000;
    print counts, expect "ZZ" of bell();
}

Kernels, tasks, main

  • quantum: a circuit specialized for its arguments at call time. Classical loops and if are evaluated at compile time; measure and feed-forward (if m { x q[2]; }) give dynamic circuits.
  • Kernels can call sub-kernels that take qubit parameters: quantum entangle(a: qubit, b: qubit) { h a; cx a, b; }.
  • task … on cpu|worker|any: classical work, local or offloaded.
  • main: orchestration; parallel { … } runs branches simultaneously.

Gates

h x y z s sdg t tdg sx · rx ry rz p · cx cz swap cp crz · ccx. Bit strings follow Qiskit's convention (qubit 0 on the right).

Compilation chain

Source → AST → SQIR circuit (JSON intermediate representation) → optimizer (inverse-pair cancellation, rotation merging) → backend, or OpenQASM 3 export.

BackendState
statevectorBuilt-in exact NumPy simulator
aerQiskit Aer (quantum extra)
qasm3OpenQASM 3 export, reloaded successfully by Qiskit in a test
qirQIR base-profile export for static circuits, validated with pyqir
qpuIBM Quantum through qiskit-ibm-runtime (qpu extra). Needs a token and an instance; otherwise refuses with the reason, no silent fallback. Not yet run on hardware.

Orchestrator refusals

A circuit whose state vector (16 × 2n bytes) exceeds half of the available RAM is refused with an explicit message. On the reference Mac: about 27 qubits.

The full grammar is in docs/06_SPATIAL_Q_SPEC.md.
