Chaque travail là où il coûte le moins.

Spatial Computing est la couche de contrôle de votre infrastructure de calcul. Il mesure vos machines, chiffre chaque façon d'exécuter un travail — CPU, GPU, une flotte, des étages de mémoire, le quantique — exécute la moins chère qui reste correcte, et enregistre l'estimation à côté de ce qui s'est vraiment passé.

Un coût par travail plus bas

Une seule formule pour tous les moteurs : l'option correcte la moins chère dans vos limites de délai, de mémoire et d'isolation, avec les prix que vous fixez.

Plus du matériel que vous avez

Flotte

Voyez chaque machine. Placez le travail où il convient.

Un agent sur chaque machine, un hub qui les voit toutes. Le travail est placé selon l'éligibilité et la charge, partagé équitablement entre équipes, et les recommandations arrivent avec leurs preuves.

  • Équité entre locataires, groupes tout-ou-rien, routage par affinité de cache
  • Un tableau de bord en lecture seule et des alertes quand un nœud se tait

Accélérateurs

Écrivez le noyau une fois. Exécutez-le sur le périphérique le moins cher.

Une source dans un sous-ensemble typé de Python devient du code CPU, un noyau GPU Metal et des sources CUDA, HIP et Triton. Le planificateur sonde chaque périphérique et choisit le moins cher pour votre taille — un noyau scientifique et un score logiciel en lot sont le même problème de placement pour lui.

  • Noyaux entiers identiques au bit sur CPU et GPU
  • Scores en lot logiciels (fraude, classement, anomalie) placés et mesurés comme un noyau scientifique
En savoir plus →
@kernel
def collatz(i: int, j: int, n: int, limit: int):
    x = i * n + j + 1
    k = 0
    while x != 1 and k < limit:
        if x % 2 == 0:
            x = x // 2
        else:
            x = 3 * x + 1
        k += 1
    return k

collatz.run("metal", 1536, limit=2000)   # 94 ms
collatz.run("cpu",   1536, limit=2000)   # 597 ms
print(collatz.to_cuda_c())               # and CUDA C / HIP source

Interconnexion

Collectives entre processus, algorithme choisi pour vous.

All-reduce et diffusion sur des liens chiffrés. Un modèle de coût mesuré choisit anneau, halving-doubling ou arbre pour chaque taille de message et nombre de processus.

  • Sommes exactes, vérifiées pour chaque algorithme
  • Calibré par algorithme à partir de vos propres mesures

  • Tableau de bord local derrière une clé aléatoire, alertes avec webhook optionnel

SPATIAL Q

Un langage pour les workflows hybrides.

Étapes classiques, distribuées et quantiques dans un seul programme. L'orchestrateur choisit un moteur d'après une estimation de ressources.

examples/01_bell.sq
// Quantum only: Bell pair. Expect ~50% "00" and ~50% "11".
quantum bell() {
    qubit q[2];
    h q[0];
    cx q[0], q[1];
}

main {
    let counts = sample bell() shots 2000;
    print "bell counts:", counts;
    print "<ZZ> =", expect "ZZ" of bell();
}
