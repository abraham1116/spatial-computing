Journal des versions

Ce qui change à chaque version.

0.14.0

  • Élection à la majorité du hub pour trois hubs ou plus (sûreté de l'élection, pas un journal répliqué).
  • Noyaux : réductions de toute la grille avec mémoire partagée (Metal), génération de source HIP, vérification des noms réservés.
  • Test d'endurance, workflow hebdomadaire de revérification, nouvelles pages du site.

0.13.0

  • Bascule du hub actif/secours (environ 6,7 s mesurées), tableau de bord en lecture seule, alertes avec webhook optionnel.

0.12.x

  • Interconnexion virtuelle, noyaux portables, équité / groupes / affinité de cache dans le hub.
  • Durcissement du protocole (délai de poignée de main, plafond de connexions, file d'écoute), persistance du hub, tests d'échelle et de fuzzing.
  • Planificateur : une troisième sonde quand les deux premières ne séparent pas le coût fixe de la vitesse.

0.11.0

  • Fabric d'accélérateurs : un travail sur CPU, Metal ou NVIDIA, choisi par le coût mesuré.

0.10.0

  • Un seul objectif pour tous les moteurs : le planificateur.

0.9.0

  • Flotte : agent, hub, recommandations.
