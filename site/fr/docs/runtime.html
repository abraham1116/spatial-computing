Runtime Engine

Inspecte un binaire, énumère les routes d'exécution possibles avec la raison de chaque refus, et exécute la première réalisable.

Inspecter et planifier

spatial plan identifie le format (Mach-O, ELF, PE, WASM, script), le système et l'architecture visés d'après les en-têtes, puis liste les routes. Une route n'est marquée réalisable que si ses prérequis ont été détectés sur la machine.

Exécuter

spatial run prend la première route réalisable (ou celle donnée par --route) et renvoie la sortie du programme.

WindowsAvec Wine présent, un binaire Windows console s'exécute et rend la somme de référence. Sans Wine, le moteur le dit au lieu de faire semblant. Wine n'est jamais installé automatiquement (binaire tiers, accord de l'utilisateur requis). Une fenêtre graphique du Bloc-notes de Wine a été vue à l'écran ; aucune autre application graphique n'a été essayée.
