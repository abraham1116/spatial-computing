Installation

Python 3.10 ou plus récent. Testé sur macOS 13 (Intel) avec Python 3.13.

Pas encore sur PyPIL'installation se fait depuis les sources du dépôt GitHub.

1. Environnement

git clone https://github.com/abraham1116/spatial-computing && cd spatial-computing
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[quantum]"

L'extra quantum ajoute Qiskit, Qiskit Aer et l'importeur OpenQASM 3. Sans lui, SPATIAL Q fonctionne avec son simulateur intégré mais pas avec le backend aer.

Les versions de numpy (< 2.2) et numba (< 0.62) sont bornées : Numba 0.62 et plus a besoin d'un llvmlite qui ne se compile pas sur ce Mac.

2. Vérifier

spatial audit
spatial status
pytest

3. Micro-VM Linux (facultatif)

La route microvm du Runtime Engine demande QEMU (par exemple sudo port install qemu avec MacPorts) et deux fichiers téléchargés une fois dans vendor/, vérifiés par empreinte SHA-256.

mkdir -p vendor && cd vendor
curl -O https://dl-cdn.alpinelinux.org/alpine/v3.22/releases/x86_64/netboot/vmlinuz-virt
curl -o busybox-x86_64 https://busybox.net/downloads/binaries/1.35.0-x86_64-linux-musl/busybox
shasum -a 256 -c SHA256SUMS

4. Binaires de test (facultatif)

Pour reproduire les tests du runtime, installe l'extra build (compilateur croisé ziglang) puis lance spatial bench runtime : il compile le même programme C pour macOS, Linux, Windows et WASM dans benchmarks/build/.
