SPATIAL Q

Un langage de flux hybride : classique, distribué et quantique, avec choix de backend par estimation de ressources.

HonnêtetéTout ce qui s'exécute est de la simulation classique. Aucun QPU n'est connecté et aucune accélération quantique n'est mesurée.

Un programme

quantum bell() {
    qubit q[2];
    h q[0];
    cx q[0], q[1];
}

task heavy(n: int) on any {
    return workload("mandel_numba", n = n, iters = 200);
}

main {
    let counts = sample bell() shots 2000;
    print counts, expect "ZZ" of bell();
}

Noyaux, tâches, main

  • quantum : circuit spécialisé pour ses arguments au moment de l'appel. Boucles et if classiques évalués à la compilation ; measure et rétroaction (if m { x q[2]; }) pour les circuits dynamiques.
  • task … on cpu|worker|any : travail classique, local ou déporté.
  • main : orchestration ; parallel { … } lance des branches simultanées.

Portes

h x y z s sdg t tdg sx · rx ry rz p · cx cz swap cp crz · ccx. Les chaînes de bits suivent la convention de Qiskit (qubit 0 à droite).

Chaîne de compilation

Source → AST → circuit SQIR (représentation intermédiaire JSON) → optimiseur (annulation de paires inverses, fusion de rotations) → backend, ou export OpenQASM 3.

BackendÉtat
statevectorSimulateur exact NumPy intégré
aerQiskit Aer (extra quantum)
qasm3Export OpenQASM 3, rechargé avec succès par Qiskit dans un test
qpuNon connecté : refuse de s'exécuter, sans repli silencieux

Refus de l'orchestrateur

Un circuit dont le vecteur d'état (16 × 2n octets) dépasse la moitié de la RAM disponible est refusé avec un message explicite. Sur ce Mac : environ 27 qubits.

La grammaire complète est dans docs/06_SPATIAL_Q_SPEC.md.
